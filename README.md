# Battleship

A browser-based Battleship game built with JavaScript.

## Features

- Place ships on a game board
- Take turns attacking the opponent's board
- Track hits and misses
- Play against a computer opponent
- Randomize ship placement and computer attacks

## Tech Stack

- JavaScript (ES modules)
- HTML
- CSS
- Webpack
- Jest

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/HaydenBerberich/battleship.git
cd battleship
npm install
```

Run the available scripts in `package.json` to start the development server, run tests, or build the project.

## Project Structure

Application logic is separated into modules for ships, game boards, players, and DOM interaction. Tests cover the core game logic.
